# Digital-Marketing-Analysis
Analysis using SQL

This dataset consists of Digital Marketing Information consisting of column Campaign Type, Campaign Channel

Findings / Insights
1. Convertion rate is 87%
2. Females have higher conversion rate
3. Middle aged has higher conversion than young and adult age category
4. Best Campaign channel Referral
